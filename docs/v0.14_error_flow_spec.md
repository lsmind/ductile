# v0.14 错误流规格 — 全自动错误处理（Either 内部值语义）

> 状态：**已落地**（a1–a4 + v0.14b/c/d）· 2026-09-08 与源码对齐  
> 用户裁定：① 错误处理不进 `.eval`——分类+策略统一收进 `errflow.rs`；  
> ② **不保留显式 left/right**——错误流是引擎内部值语义，DSL 零新增语法。

---

## 0. 问题（历史动机）

改造前错误语义只有一层：`exec_proc` 全路径失败 → 整管线 abort。缺陷：

1. 错误是控制流不是数据——无错误消费者
2. 部分结果全丢——Failed 不带 partial
3. 错误不可分类——timeout 与权限同一种字符串
4. 策略缺失——权限被无谓重试、数据错重复撞墙

## 1. 设计总纲

```
原始错误 ──→ errflow.rs ──→ executor 内部 Either 值语义
  stderr/io/exit/timeout    classify → ErrorRecord
                            strategy → Retry/Reroute/Escalate
                            respond  → Ignore/Wait/Switch/Exit
                            fatal_left → 仅关键链（deliver 闭包）致命
```

**全自动**：分类是引擎事实、策略是内置表、传播是隐式语义——`.pipeline` 语法零变更。

## 2. 错误分类学（十五类，v0.14d）

| 码 | 含义 | strategy | respond |
|----|------|----------|---------|
| `cancelled` | 用户中断 | Escalate | Exit |
| `timeout` | 超时 | Retry×2 | Wait |
| `ratelimit` | 429/配额 | Retry×2 | Wait |
| `memory` | OOM/137 | Retry×1 | Wait |
| `network` | 网络抖动 | Retry×2 | Wait |
| `resource` | 本地资源 | Retry×1 | Wait |
| `truncation` | 输出截断 | Retry×2 | Wait |
| `auth` | 401/凭证 | Escalate | Switch |
| `data` | 数据错 | Reroute | Switch |
| `format` | 输入格式 | Reroute | Switch |
| `schema` | 输出结构 | Reroute | Switch |
| `dependency` | 缺依赖 | Escalate | Ignore |
| `permission` | 权限 | Escalate | Ignore |
| `contract` | DSL/契约创作错 | Escalate | Exit |
| `crash` | 兜底 | Escalate | Ignore |

`classify()` 纯函数；判定顺序先具体后兜底。`ErrorRecord` 编码复用 `§§FIELDS§§`。

## 3. 内置策略（不可配置）

- **Retry{budget, backoff}**：proc 级线性退避整轮重跑（关键节点预算 ×2，见 `strategy_for`）
- **Reroute**：impl 传输层遇数据类错误立即换备选，不撞墙
- **Escalate**：不自动处理，Left 落库 + 隐式传播

与 `.retry(n)` 分工：后者是单 impl 传输层指数退避；errflow 在外层。

## 4. Either 内部值语义

1. **错误值化**：策略耗尽 → `results[p] = Left(ErrorRecord.encode())`
2. **隐式传播**：下游引用任一 Left → 本 proc 不执行、落传播 Left
3. **下游响应**：`respond(code)` 驱动 Ignore / Wait / Switch / Exit（见 executor）
4. **终局判定**：`fatal_left`——仅 **deliver 引用闭包（关键链）** 上的 Left 使管线 Failed；旁路失败容忍（Success + 标记）
5. **e-graph 路径**：与默认路径同语义——Left 落库、CSE 共享失败、继续执行，终局 `fatal_left`；仅 `respond=Exit`（如 contract）立即中止

## 5. API 面

`run_json` 失败可带 `err_code` + `partial`（Left 解码为对象）。

## 7. 边界与取舍

- **v0.9 兼容**：无新语法；失败时下游被标记传播 + Failed 携带 partial

- **策略表迭代** = 改 `errflow.rs` + 测试
- Saga 补偿（.undo）不在本期
