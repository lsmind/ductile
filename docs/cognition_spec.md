# 认知回传系统规格（cognition spec）

> 状态：纸面推演定稿，待实现（P0）。来源：两轮纸面推演 + 2026-09-09 长任务实验实证
>（ollama qwen3.8:27b 经 llm bridge 跑五阶段管线，三起真实事故走查）。
> 定位：把 ductile 从「编排引擎」升维为「LLM 经验系统」的认知层规格。

## 0. 项目哲学（四层一角色）

最终目的：**让 LLM 复用成熟的流程经验，将长任务分解为短任务自动规划并执行。**

1. **长任务分解**：成熟流程沉淀为 DSL（pipeline），长任务分解为短任务规划执行。
2. **认知上下文管理**：LLM 节点不可避免，引擎自动向其提供**最小必要信息**。
3. **认知反向传播**：子节点出错 → 归因「节点描述与预期不符」→ 修正节点认知 →
   逐步向上完成整个流程的认知迭代（类比反向传播）。
4. **超网络经验**：DAG 无法回传结构信息 → hyper 层承载结构的生成与反馈，
   同构结构可复用、可约束、可积累经验。
5. **角色分层**：caller / maintainer / designer 三种专用 LLM 角色，各看各的上下文。

**核心公式（对齐修正后）**：

> 确定性不变量产生误差信号 → 五分类归因闸过滤 → 补丁 = 带置信度的可证伪假设 →
> 确认运行晋升为经验 → 按（结构 × 认知）双轴写入 hyper → 复用时相似度门控迁移。
> LLM 出现三次，都不是裁判：归因（为什么错）、提案（怎么改）、设计（结构生成）。
> **「有没有错」永远由机器回答。**

## 1. 七层误差信号栈（L0–L5）

信号分层，成本递增；上层信号短路下层。一次运行 × 一个节点的所有信号**先束成
incident 候选**再进归因，不逐条处理。

| 层 | 名称 | 检测器 | 证据形态 | 误报策略 |
|---|------|--------|---------|---------|
| L0 | 传输 | exit code / timeout / network（errflow 已有） | err_code | 近零误报 |
| L0.5 | 溯源 | 实际执行体证明：bridge 哈希、model id、finish_reason、usage | 机器可读 sidecar | 零误报（事实非判断） |
| L1 | 形式 | schema / 类型 / 字段存在 / 格式 | 字段级 diff | 低；契约本身错走 class 3 同机制修 |
| L2 | 语义不变量 | 声明式谓词（跨字段、输入输出耦合） | 谓词 ID + 违反快照 | 谓词走 tentative→confirmed 生命周期 |
| L3 | 统计 | 节点分布：长度包络、分数带宽、拒答率、语言、延迟；裁判同分布检测 | 距历史分布偏离度 | ≥K 历史才激活；冷启动只记不判 |
| L4 | 端到端 | 任务意图 vs deliver 的独立复核 | 二元 verdict + 一句话证据 | 唯一合法用 LLM 的检测层；独立会话最小上下文 |
| L5 | 归因 | 消费信号束，只答「为什么」 | class + 假设 + 判别实验 | 永不产生「有没有错」的判断 |

### 关键机制（实验实证）

- **A1 L1 盲区**：截断产生的 score=10 是合法 0-100 整数，schema 必过。抓它的是
  L0.5（finish_reason=length）与 L2 跨字段极性谓词（评语「完全匹配」vs score=10）。
  **跨字段一致性 + 完成元数据是 L1 盲区的唯一补丁，且都是确定性的。**
- **A2 桥是有损信道**：旧桥劫持事故中，模型收到 `--prompt` 字面量。一击必中的是
  「实际执行的桥是哪个文件的哈希」。要求 `##DSL_RESULT` 协议扩展 META 块
  （finish_reason / usage / bridge_hash / model_id）。**桥丢掉的恰恰是归因需要的证据。**
- **A3 检测器列表是活的**：运行时事故可提议新不变量——maintainer 归因「契约缺
  检测器」时，patch 内容就是新增谓词。认知迭代不止于改描述，还包括扩契约。

## 2. 归因五分类闸

### 2.1 类别定义与准入

| 类 | 判定 | 修复动作 | 写入 |
|---|------|---------|------|
| 1 环境故障 | L0.5 直接证据（错桥/截断/超时/断连） | 修基础设施，可选重跑 | env_incidents（TTL 30 天，统计性质） |
| 2 上游投毒 | 本节点 canary 通过 + 上游有未决异常 | 归因上移，本节点清白不落 patch | 上游的归因记录 |
| 3 描述错误 | canary 复现同病（与输入无关）+ 修 desc 后 canary 转绿 | patch desc/契约/不变量 | patches（tentative→confirmed） |
| 4 能力不足 | canary 复现同病 + 修 desc 无效（多次 patch 不确认） | 换 impl / 加 gate / 拆节点 | impl_prefs（已有）+ 结构提案队列（designer） |
| 5 分布漂移 | **须有外部变化证据**（model 版本变、任务域变），否则不准入 | 只记观测，调统计基线 | 基线漂移日志 |

两条铁律：

- **class 5 是万能逃生口**：没有外部变化证据的「诊断不了」落进来，系统什么都学不到
  还自我感觉良好。准入最严的一类。
- **最危险误分类是 class 2 → 3/4**（上游有病，patch 了受害节点 = 修症状）。
  对策硬门禁：**没有 canary 通过记录，禁止任何本地 patch。**

### 2.2 判定程序（四步，成本递增）

```
Step 0  证据束组装：本节点全部信号 + 同运行上下游信号 + 该节点 patch 史
Step 1  确定性预分类（零 LLM）：
        finish_reason=length + 字段缺失/截断 → class 1 终态
        桥哈希/环境证明不匹配 → class 1 终态
        （预估可终结 60–70% 事故）
Step 2  canary 探针（一次受控重跑）：
        用设计期存档的已知好输入喂本节点
        canary 绿 → 输入依赖 → class 2，归因上移
        canary 复现同病 → class 3 或 4，进 Step 3
Step 3  LLM 归因（仅疑难）：
        输入 = 证据束 + 节点契约 + patch 史
        输出必须含 {class, 假设, 判别实验, 提议 patch, 猜想置信度}
        引擎执行判别实验 → 与假设矛盾 → 丢弃重来或搁置
Step 4  类 → 动作映射（2.1 表）
        预算：每事故 ≤1 次 LLM 调用 + ≤2 比测试运行
        超预算 → incident 搁置进 designer 审队列，绝不强行分类
```

**可证伪性是 Step 3 的核心**：LLM 不许只给结论，必须给「什么结果能证明我错」的
实验，引擎执行后才接受分类。判别实验结果模糊（两个假设都活着）→ 搁置，不许猜。

### 2.3 patch 状态机

```
incident → 分类 → patch(tentative, c=置信度)
        → 影子期（只记日志不拦截，K 次运行）
        → 观察到误报 → 氧化/衰减
        → K 次干净确认 → confirmed（生效拦截）
        → 下次 .pipeline 落盘时物化进契约文件（overlay→artifact）
```

**patch 债**（每节点每月 patch 数）是健康指标：高债 = 分类错了或节点该拆，
是 class 3→4 的自动升级信号，防止对着能力天花板无限 prompt 工程。

## 3. 三起真实事故走查（2026-09-09 实验）

### 事故A：score 截断（10 ≠ 100）
- 信号束：[L0.5 finish_reason=length, L2 极性矛盾, L3 score 离群]
- Step 1 确定性预分类 → **class 1 终态，零 LLM**
- 动作：env_incidents 记录；修桥加 max_tokens；不产生认知 patch
- 对照：人工修复同样是「修环境不修认知」。✅

### 事故C：旧桥劫持（prompt 变 `--prompt` 字面量）
- Step 1 桥哈希 ≠ 仓库桥 → **class 1 绥态，零 LLM**
- 对照：人工靠人肉看模型输出才破案；溯源层让它在语义检查之前终态。✅

### 事故B：plan 跑偏 + judge 放行（全绿假成功）——两个 incident

**plan 节点**：
- L2 锚点谓词（每步须引用任务原文关键词）违例
- canary：喂简单已知任务仍产出行政性步骤 → 与输入无关 → 排除 class 2
- 判别实验：desc 加锚点条款重跑 → 同模型产出质变 → **class 3（描述欠约束）**
- patch：planner 族 desc 模板加锚点子句 + 新增锚点谓词进契约
- 对照：机器重新发现了人工修复，且变成可迁移的族级认知。✅

**judge 节点**：
- L1/L2 全过（score≥80 契约满足）——病只有在 L4 端到端才显形
- 归因：模型没问题、prompt 没问题，**是 judge 契约本身不完备**
- class 3，但 patch 内容 = 给 judge 节点新增不变量（judge 分数分布与下游任务
  成功率的相关性下限，L3 统计检测）
- 长线：积累历史后发现 judge 分数恒 78–85 与任务成败零相关 →「橡皮图章裁判」
  检测器自动上线（A3 的实例）

## 4. 角色与上下文（P3）

| 角色 | 最小上下文 | 职责 | 写权限 |
|------|-----------|------|--------|
| caller | 意图 + 结果卡 | 发起任务 | 无 |
| maintainer | 全量证据束 + 节点契约 + patch 史 | 归因、提议 patch | patches（节点认知） |
| designer | hyper 图 + 结构统计 + 提案队列 | 结构生成、canary 库维护、超网络回填 | hyper（结构） |

- 归因需要**最大**上下文，caller 只需要最小——「最小」按角色定义。
- 压缩制造错误：摘要节点丢了截断标记，下游归因不可能成功。上下文卡必须带
  **指针 + 按需展开**（pull 模型），压缩是默认值不是强制值。
- 跨层建议走队列提案，不直写（双写冲突）。

## 5. 超网络回填（P2）

- runs 统计按 hyper vertex 聚合（gate 拦截率、节点失败率、路径耗时）写回 `.hyper`
  成为软约束/偏好权重。
- 结构经验按**（结构签名 × tags × impl 族）三轴定位**。devcycle 的 grep gate 与
  实验里的 27B judge 结构同构、认知异构——只按结构签名聚合会让「judge 不稳定
  建议重试」错误迁移到 grep 门上。相似度门控必须包含认知标签。

## 6. 上轮推演的 8 个问题与本规格的关闭情况

| # | 问题 | 关闭机制 |
|---|------|---------|
| ① | 归因歧义（五分类） | §2 五分类闸 + canary 硬门禁 |
| ② | 补丁是假设不是真理 | 可证伪归因 + 影子期 + 置信衰减 |
| ③ | 裁判自指 | §1 分层信号，LLM 只在 L4/L5，确定性证据短路 LLM |
| ④ | 最小/最大上下文不对称 | §4 角色上下文表 + pull 模型指针卡 |
| ⑤ | 超网络同一性 | §5 三轴定位 + 相似度门控 |
| ⑥ | 回传震荡 | canary 硬门禁 + 单节点 patch + patch 债升级 |
| ⑦ | 双写冲突 | §4 写权限表 + 提案队列 |
| ⑧ | 描述双语漂移 | patch 可物化为谓词，NL 引用谓词 ID |

### 7.1 实现中沉淀的工程教训

- **LLM 输出一律不进 bash**：`echo '@ref'` 与 `>/dev/null` 重定向都不是消毒——
  内容过 shell 解析就会被打出来的单引号炸掉。合法路径只有 `.when` 结构化字段与
  `write` 动词落盘（SPEC §13.5）。
- **环境变量必须真的被读**：`DUCTILE_DATA` 曾是被 selftest 导出却从未被 `db_path()`
  读取的幽灵变量，所有"隔离"探针实际在写真库。
- **cargo test 继承 shell 环境**：`export DUCTILE_L4=1` 后跑测试会把单测的复核
  写进真库——`l4_finalize` 加 `cfg!(test)` 守卫。
- **测试禁 set_var 全局 env**：并行测试下会把别的线程的 `db::open()` 重定向到
  即将删除的临时目录（flaky）；改参数注入（`db_path_with`）。
- **rusqlite 参数计数**：无占位符 SQL 绑定 `params![Option]` 报错但被 `let Ok(..)`
  吞掉——查询面静默返回空表，必须显式分支绑定。

## 8. 不做什么（负空间）

- 不做 LLM 全权裁判（L4 是唯一 LLM 检测层，且独立会话）。
- 不做无 canary 的本地 patch（硬门禁）。
- 不做无外部变化证据的 class 5 归因。
- 不做全量上下文注入 caller/maintainer（角色最小上下文 + pull 展开）。
- 不做跨角色直写（提案队列隔离）。
